# Verify traceability structure, completeness, and objective evidence

Verify traceability structure, completeness, and objective evidence

## Usage

``` r
validateTraceability(x, verify_evidence = TRUE)
```

## Arguments

- x:

  A `traceability_matrix`.

- verify_evidence:

  Whether to hash evidence files under the recorded evidence root.

## Value

A `traceability_verification` object.
