# Extract the compliance audit trail

Extract the compliance audit trail

## Usage

``` r
auditTrail(x)
```

## Arguments

- x:

  A
  [PhysioCore::PhysioExperiment](https://x-biosignal.github.io/PhysioCore//reference/PhysioExperiment.html)
  object.

## Value

An `audit_trail` data frame with a `details` list-column. An
uninitialized object returns a zero-row trail.
